# Character sprite sheets

All characters (Leo, Eve, etc.) share the same 6-column grid. Cell indices are defined in `open_tts/sprite.py`.

| Row | Purpose |
|-----|---------|
| 0 | Vowels + rest: `a` `e` `i` `o` `u` `pause` |
| 1 | Consonant visemes: `mbp` `fv` `th` `l` `sz` `sh` |
| 2 | Expressions: `surprise` `laugh` (cols 0–1) |
| 3+ | Expression animation frames (2 rows) |

`pause` is the closed-rest mouth; `mbp` is the closed speech shape (P/B/M). Do not alias them.

Placeholder PNGs are generated by `ensure_placeholder_sheet` when a sheet path is missing.
